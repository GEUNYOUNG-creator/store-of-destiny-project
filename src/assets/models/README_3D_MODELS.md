# 운명상점 3D 캐릭터 모델 (.glb) 가이드

이 폴더(`src/assets/models/`)에 아래 파일명으로 `.glb` 3D 모델을 넣으면, 앱이 자동으로 기존 2D 일러스트 대신 **실제 3D 리깅 캐릭터**로 불러와 렌더링합니다. (아직 `.glb`가 없는 캐릭터는 기존 일러스트로 자연스럽게 표시됩니다.)

## 추천 내보내기 설정 (Tripo AI / Meshy / Mixamo)
- **포맷**: `.glb` (Binary glTF, 텍스처 내장)
- **권장 용량**: 캐릭터당 `2MB ~ 5MB` 이하 (모바일 로딩 속도 최적화)
- **권장 폴리곤**: `15,000 ~ 40,000` 트라이앵글
- **리깅(뼈대) & 애니메이션**:
  - Auto-Rig 적용 후 **Idle(대기)** 모션을 포함해 내보내면 앱의 `AnimationMixer`가 자동으로 루프 재생합니다.
  - 본(Bone) 이름이 `Head`, `Neck`, `Spine`, `Chest` 등 표준 휴머노이드 이름이면 시선 추적·호흡·보이스 대화 고개 끄덕임이 자동으로 함께 작동합니다.
